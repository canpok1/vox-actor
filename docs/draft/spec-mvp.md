# 仕様書：vox-actor（MVP）

`vox-actor` は、音声合成エンジンを介して台本（Script）を演じるための CLI ツールです。Go 言語で開発された単一バイナリとして配布され、クロスプラットフォームで動作します。

本ドキュメントは MVP 版の仕様です。最終版の仕様は [spec.md](./spec.md) を参照してください。

---

## 1. 概要

指定されたファイルまたはディレクトリ内の台本データを読み取り、VOICEVOX エンジンで音声合成して再生します。

## 2. システム構成

* **動作環境**: Go で作成された単一バイナリ。
* **音声合成**: VOICEVOX エンジン（HTTP API）を利用。
* **再生**: [gopxl/beep](https://github.com/gopxl/beep) ライブラリによるアプリ内オーディオ再生。

## 3. コマンド構成

```bash
vox-actor act [options] <path>
```

### オプション

| オプション | デフォルト値 | 説明 |
| --- | --- | --- |
| `--engine-url <url>` | `http://localhost:50021` | VOICEVOX エンジンの URL |
| `--speaker <id>` | `3`（ずんだもん） | キャラクター ID |
| `--speed <float>` | `1.0` | 話速（目安: 0.5 〜 2.0） |
| `--pitch <float>` | `0.0` | 音高（目安: -0.15 〜 0.15） |
| `--intonation <float>` | `1.0` | 抑揚（目安: 0.0 〜 2.0） |

### 動作

* `path` がファイルの場合: そのファイルを読み上げて終了。
* `path` がディレクトリの場合: ディレクトリ内のファイルを辞書順に一通り読み上げて終了。

## 4. 台本データ形式

`.txt` ファイルのみ対応。ファイル全内容を一つのセリフとして、CLI オプションで指定されたパラメータで読み上げます。

* テキストファイルの文字コードは **UTF-8** 固定（BOM 付き UTF-8 も許容）。
* パラメータの目安値はガイドラインであり、アプリ側でのバリデーションは行わない（エンジン側の挙動に委ねる）。

## 5. 実行フロー

1. **起動時チェック**: VOICEVOX エンジンへの疎通確認を行う。接続できない場合はエラー終了。
2. **読み込み**: 指定されたパスからファイルを取得（ディレクトリの場合は辞書順）。
3. **演奏（Performance）**: ファイルを解析し、パラメータに基づき VOICEVOX API で音声を生成・再生。
4. **終了**: 全ファイルの読み上げが完了したら終了。

## 6. エラーハンドリング

| エラー種別 | 挙動 |
| --- | --- |
| **起動時のエンジン接続失敗** | エラーメッセージを出力し、即座に終了。 |
| **空ファイル** | エラーログを出力し、スキップして次のファイルへ。 |
| **音声再生失敗** | リトライなし。エラーログを出力し、即座にエラー終了。 |

## 7. 終了コード

| コード | 意味 |
| --- | --- |
| `0` | 正常終了（全ファイルの読み上げ完了） |
| `1` | エラー終了（エンジン接続失敗、音声再生失敗等） |
| `2` | 引数エラー（不正なオプション、パスが存在しない等） |

## 8. 利用者環境準備

* **エンジン**: VOICEVOX エンジン（Docker またはデスクトップ版）が起動済みであること。

---

## MVP 版スコープ外（最終版で対応）

* `.json` 単一台本モード（感情制御パラメータの JSON 指定）
* `.jsonl` 朗読劇モード
* 監視モード（`act --watch` による単一ディレクトリ監視、`watch` による複数ディレクトリ監視）
* 環境変数による設定（`VOX_ENGINE_URL`, `VOX_SPEAKER`）
* `--verbose` による詳細ログ
* 処理中のエンジン接続リトライ
* 処理済みファイルの `done/` への移動
* グレースフルシャットダウン
