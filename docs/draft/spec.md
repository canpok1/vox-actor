# 仕様書：vox-actor

`vox-actor` は、音声合成エンジンを介して台本（Script）を演じるための CLI ツールです。Go 言語で開発された単一バイナリとして配布され、クロスプラットフォームで動作します。

本ドキュメントは最終版の仕様です。MVP 版の仕様は [spec-mvp.md](./spec-mvp.md) を参照してください。

---

## 1. 概要

`vox-actor` は、指定されたディレクトリを監視し、投入されたテキストや台本データを読み取って音声として出力します。特定の開発環境に依存せず、外部音声合成エンジン（VOICEVOX）と連携して「台本を演じる（Act）」ことを目的としたツールです。

## 2. システム構成

* **動作環境**: Go で作成された単一バイナリ。
* **音声合成**: VOICEVOX エンジン（HTTP API）を利用。
* **再生**: [gopxl/beep](https://github.com/gopxl/beep) ライブラリによるアプリ内オーディオ再生。

## 3. コマンド構成

```bash
vox-actor act [options] <path>
```

### オプション

| オプション | 環境変数 | デフォルト値 | 説明 |
| --- | --- | --- | --- |
| `--engine-url <url>` | `VOX_ENGINE_URL` | `http://localhost:50021` | VOICEVOX エンジンの URL |
| `--speaker <id>` | `VOX_SPEAKER` | `3`（ずんだもん） | デフォルトのキャラクター ID |
| `--watch` | — | `false` | ディレクトリ監視モードを有効化 |
| `--verbose` | — | `false` | 詳細ログを出力 |

オプションの優先順位: **CLI フラグ > 環境変数 > デフォルト値**

### 動作モード

#### 通常モード（デフォルト）

* `path` がファイルの場合: そのファイルを読み上げて終了。
* `path` がディレクトリの場合: ディレクトリ内のファイルを辞書順に一通り読み上げて終了。

#### 監視モード（`--watch`）

指定されたディレクトリを監視し、ファイル投入を検知して順次読み上げを行います。`path` にはディレクトリを指定する必要があります。

## 4. 台本データ形式

ファイルの拡張子に応じて、以下のモードで解析・読み上げを行います。

| 拡張子 | 解析モード | 仕様 |
| --- | --- | --- |
| **`.txt`** | テキストモード | ファイル全内容を一つのセリフとして、デフォルト設定で読み上げ。 |
| **`.json`** | 単一台本モード | JSON オブジェクトとして解析し、指定された感情パラメータで読み上げ。 |
| **`.jsonl`** | 朗読劇モード | 行ごとに JSON を解析し、順番に連続して読み上げ。 |

* テキストファイルの文字コードは **UTF-8** 固定（BOM 付き UTF-8 も許容）。

## 5. 感情制御パラメータ（JSON/JSONL共通）

各セリフにおいて、以下のパラメータを指定可能です。

| パラメータ | 型 | 必須 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| `text` | string | **必須** | — | 読み上げる文章 |
| `speaker` | int | 任意 | CLI の `--speaker` 値 | 使用するキャラクター ID |
| `speedScale` | float | 任意 | `1.0` | 話速（目安: 0.5 〜 2.0） |
| `pitchScale` | float | 任意 | `0.0` | 音高（目安: -0.15 〜 0.15） |
| `intonationScale` | float | 任意 | `1.0` | 抑揚（目安: 0.0 〜 2.0） |

* 範囲の目安値はガイドラインであり、アプリ側でのバリデーションは行わない（エンジン側の挙動に委ねる）。

## 6. 実行フロー

### 共通

1. **起動時チェック**: VOICEVOX エンジンへの疎通確認を行う。接続できない場合はエラー終了。

### 通常モード

2. **読み込み**: 指定されたパスからファイルを取得（ディレクトリの場合は辞書順）。
3. **演奏（Performance）**: ファイルを解析し、パラメータに基づき VOICEVOX API で音声を生成・再生。連続するセリフ（`.jsonl`）は、前の再生終了を待機して順次再生。
4. **終了**: 全ファイルの読み上げが完了したら終了。

### 監視モード（`--watch`）

2. **監視**: 指定されたディレクトリを常時監視。
3. **キューイング**: 新規ファイルが作成されると、ファイル名の辞書順で内部キューに追加。
4. **演奏（Performance）**: ファイルを解析し、パラメータに基づき VOICEVOX API で音声を生成・再生。連続するセリフ（`.jsonl`）は、前の再生終了を待機して順次再生。
5. **ファイル移動**: 処理完了後（正常・異常問わず）、該当ファイルを監視ディレクトリ直下の `done/` サブディレクトリに移動。

## 7. エラーハンドリング

| エラー種別 | 適用モード | 挙動 |
| --- | --- | --- |
| **起動時のエンジン接続失敗** | 共通 | エラーメッセージを出力し、即座に終了。 |
| **処理中のエンジン接続失敗** | 共通 | リトライを実施。リトライ上限超過でエラー終了。 |
| **不正な JSON / 空ファイル** | 通常 | エラーログを出力し、スキップして次のファイルへ。 |
| **不正な JSON / 空ファイル** | 監視 | エラーログを出力し、ファイルを `done/` に移動してスキップ。 |
| **音声再生失敗** | 共通 | リトライなし。エラーログを出力し、即座にエラー終了。 |

## 8. 終了処理

* **Ctrl+C / SIGTERM** 受信時: 現在再生中の音声を最後まで再生し、キューの残りは破棄してグレースフルに終了。

### 終了コード

| コード | 意味 |
| --- | --- |
| `0` | 正常終了（全ファイルの読み上げ完了、またはグレースフルシャットダウン完了） |
| `1` | エラー終了（エンジン接続失敗、音声再生失敗等） |
| `2` | 引数エラー（不正なオプション、パスが存在しない等） |

## 9. ログ出力

* 標準エラー出力にテキスト形式で出力。
* 通常時: 処理状況を簡潔に表示（ファイル検知、再生開始/完了、エラー等）。
* `--verbose` 指定時: API リクエスト詳細、パラメータ値等のデバッグ情報を追加出力。

## 10. 利用者環境準備

* **エンジン**: VOICEVOX エンジン（Docker またはデスクトップ版）が起動済みであること。
