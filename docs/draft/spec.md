# 仕様書：vox-actor

`vox-actor` は、音声合成エンジンを介して台本（Script）を演じるための CLI ツールです。Go 言語で開発された単一バイナリとして配布され、クロスプラットフォームで動作します。

---

## 1. 概要

`vox-actor` は、指定されたディレクトリを監視し、投入されたテキストや台本データを読み取って音声として出力します。特定の開発環境に依存せず、外部音声合成エンジン（VOICEVOX 等）と連携して「台本を演じる（Act）」ことを目的としたツールです。

## 2. システム構成

* **動作環境**: Go で作成された単一バイナリ。
* **音声合成**: 外部の VOICEVOX エンジン（HTTP API）を利用。
* **再生**: OS 標準のオーディオ再生コマンドを利用。

## 3. コマンド構成

```bash
vox-actor act watch [options] <watch_directory>

```

### サブコマンド `act watch` の仕様

指定されたディレクトリを監視し、ファイル投入を検知して以下のモードで順次読み上げを行います。

| 拡張子 | 解析モード | 仕様 |
| --- | --- | --- |
| **`.txt`** | テキストモード | ファイル全内容を一つのセリフとして、デフォルト設定で読み上げ。 |
| **`.json`** | 単一台本モード | JSON オブジェクトとして解析し、指定された感情パラメータで読み上げ。 |
| **`.jsonl`** | 朗読劇モード | 行ごとに JSON を解析し、順番に連続して読み上げ。 |

## 4. 感情制御パラメータ（JSON/JSONL共通）

各セリフにおいて、以下のパラメータを指定可能です。

* `text` (string): 読み上げる文章（必須）。
* `speaker` (int): 使用するキャラクターID。
* `speedScale` (float): 話速（0.5 〜 2.0）。
* `pitchScale` (float): 音高（-0.15 〜 0.15）。
* `intonationScale` (float): 抑揚（0.0 〜 2.0）。

## 5. 実行フロー

1. **監視**: 指定された `WATCH_DIRECTORY` を常時監視。
2. **キューイング**: 新規ファイルが作成されると、内部キューに追加。
3. **演奏（Performance）**:
* ファイルを解析し、パラメータに基づき音声を生成。
* 連続するセリフ（`.jsonl`）は、前の再生終了を待機して順次再生。


4. **クリーンアップ**: 読み上げ完了後、該当ファイルを即座に削除。

---

## 6. 利用者環境準備

* **エンジン**: VOICEVOX エンジン（Docker または デスクトップ版）が起動済みであること。
* **再生環境**: OS 標準の再生コマンドがインストールされている環境。
