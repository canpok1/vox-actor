# 作業メモ（work-memo）スキル利用ルール

複数ステップに渡る長時間の作業を行う場合、`work-memo` スキルを使って作業メモを記録すること。記録の粒度やタイミングはLLMが作業内容に応じて判断する。

## 記録タイミングの目安

以下のタイミングでメモに追記する。

- **作業開始時**: メモファイルを作成（既存ファイルがあれば追記）し、目的と作業内容チェックリストを設定する
- **区切りの良いタイミング・各ステップ完了時**: 作業ログへ追記する（実装内容、成果物、遭遇した問題など）
- **想定外のことが起こったとき・重要な決断をしたとき**: 判断内容と理由を作業ログへ追記する
- **作業内容チェックリストのタスクが完了したとき**: チェックを付ける

1ステップで完結する短い作業や、記録する価値のない定型作業では省略してよい。
