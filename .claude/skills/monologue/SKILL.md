作業の開始時や終了時に、キャラクターになりきった独り言を通知します。

## 通知の仕組み

1. 乱数を生成し、通知確率に基づいて通知するかどうかを判定する
2. 通知する場合のみ、キャラクター設定に基づいた一言コメントを生成し、`notify-host.sh` で通知する
3. 通知しない場合は何もせずに終了する

### 通知確率

- 初期値: 10%（10回に1回）
- ユーザーの指示により調整可能（Claudeのメモリシステムに保存する）
  - 例: 「独り言の頻度を30%にして」→ メモリに `monologue_probability: 30` を保存

### 乱数の生成と判定

Bashで乱数を生成して判定する:

```bash
# 1〜100の乱数を生成
ROLL=$((RANDOM % 100 + 1))
# メモリに保存された確率（デフォルト10）と比較
# ROLL <= 確率 なら通知する
```

### 通知の実行

判定が通知する場合のみ、以下を実行する:

```bash
.claude/skills/monologue/scripts/monologue.sh "（キャラクターの一言コメント）"
```

## キャラクター設定

使用するキャラクターの設定ファイルを読み込み、そのキャラクターになりきった一言コメントを生成する。

- デフォルトキャラクター: ずんだもん
- キャラクター設定ファイル: `characters/zundamon.md`

## メモリに保存する設定項目

以下の設定をClaudeのメモリシステム（MEMORY.md）に保存・参照する:

| 項目 | キー | デフォルト値 | 説明 |
|------|------|-------------|------|
| 通知確率 | `monologue_probability` | 10 | 1〜100の整数。通知する確率（%） |
| キャラクター | `monologue_character` | zundamon | 使用するキャラクター名 |

## 制約

- 通知の実行は必ず乱数判定を経ること（毎回通知しない）
- 通知コメントは1文程度の短い独り言にすること
- 作業の流れを妨げないよう、スキルの実行は素早く完了すること
