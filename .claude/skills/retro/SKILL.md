振り返りを行います。
実装は行いません。振り返りと作業メモへの記録、メモファイルの移動のみに専念します。

## 禁止事項

- **コードの実装・修正を絶対に行わないこと**（作業メモファイル以外のファイル編集、Write、Edit ツールの使用は禁止）
- **コミット・プッシュを行わないこと**
- **ブランチの作成・切り替えを行わないこと**
- **GitHub Issueを作成しないこと**（振り返り結果は作業メモへの記録に留める。Issue化は `memo-to-issue` スキルの責務）
- 改善案は直接実装しないこと
- 振り返り後に「続けて実装しましょう」等と提案しないこと

## ワークフロー

1. 直前の作業内容を振り返る
  - 作業メモファイルが存在する場合は参照する
    - メモファイルのパス特定方法は `work-memo` スキルを参照する
  - 実施タスク
  - 使用したスキル/エージェント
  - スムーズだった点
  - 問題点

2. 改善案をまとめる
  - 改善することがなければ改善案なしとする
  - 改善案には、ルール（`.claude/rules/`）やスキル定義（`.claude/skills/`）への明文化を含めること
  - 変更対象となるルールファイルやスキル定義ファイルのパスを特定すること

3. 振り返り結果を作業メモに記録する
  - `work-memo` スキルに従ってメモファイルのパスを取得する
  - 既存のメモファイルがあれば Read で読み取ってから追記する（上書き禁止）
  - メモファイルが存在しない場合は新規作成する
  - 作業ログセクションに「振り返り」ステップを追記する
  - 記録内容には以下を含めること
    - スムーズだった点
    - 問題点
    - 改善案（変更対象となるルール・スキル定義ファイルのパスを含む）

4. 作業メモを完了ディレクトリへ移動する
  - 改善案の有無にかかわらず、このステップを必ず実施する
  - 移動先: `${WORKSPACE_DIR}/.tmp/memo/done/`
  - ディレクトリが存在しなければ作成する
  - 同名ファイルが既に存在する場合はタイムスタンプ付きでリネームして衝突を回避する
  - Bash コマンド例：
    ```bash
    SRC="<現在の作業メモの絶対パス>"
    DEST_DIR="${WORKSPACE_DIR}/.tmp/memo/done"
    mkdir -p "$DEST_DIR"
    BASE=$(basename "$SRC" .md)
    TARGET="$DEST_DIR/$BASE.md"
    if [[ -e "$TARGET" ]]; then
        TS=$(date +%Y%m%d%H%M%S)
        TARGET="$DEST_DIR/$BASE.$TS.md"
    fi
    mv "$SRC" "$TARGET"
    ```

5. 振り返りの内容と移動先パスをユーザーに報告する

## 完了条件

- 振り返り内容の報告、作業メモへの記録、`done/` への移動をもって**完了**とする
- 実装やIssue作成には進まず、ここで終了すること
